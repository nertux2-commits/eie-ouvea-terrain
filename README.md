# EIE Ouvéa – application de terrain

Application web hors ligne (PWA) de saisie des relevés de terrain de l'état initial du défrichement BESS ENERCAL, Fajawe (Ouvéa) – DENV, Province des Îles Loyauté.

- Parties : Plantes (fiches 0 à 5), Reptiles, Fourmis, Oiseaux
- Fonctionne sans réseau (service worker) ; données stockées sur l'appareil
- Synchronisation Supabase quand le réseau est disponible (code équipe requis, non stocké dans ce dépôt)
- Exports : Excel (un onglet par fiche), photos (zip), sauvegarde JSON

Adresse : https://nertux2-commits.github.io/eie-ouvea-terrain/
